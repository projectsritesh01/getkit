# GetKit 🚀

### 🌐 Live Demo
- Frontend: https://getkit-nu.vercel.app
- Backend API: https://getkit.onrender.com

GetKit is a full-stack MERN web application designed to simplify the discovery and sharing of useful digital resources and community-driven content. The platform provides secure user authentication, protected routes, and a responsive interface that enables users to seamlessly explore and access curated articles and resources.

Built with React, Vite, Node.js, Express, and MongoDB, GetKit demonstrates modern full-stack development practices including JWT authentication, REST API integration, cloud deployment, and scalable application architecture.

## ✨ Features

- 🔐 JWT-based Authentication
- 🛡️ Protected Routes
- 📄 Resource & Article Access
- ⚡ Responsive Modern UI
- ☁️ Full Deployment using Vercel & Render
- 🗄️ MongoDB Atlas Integration

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/projectsritesh01/getkit.git
cd getkit
```
## 2️⃣ Navigate to Frontend Folder
```bash
cd frontend
```
## 3️⃣ Install Frontend Dependencies
```bash
npm install
```
## 4️⃣ Create Frontend Environment File
```bash
VITE_API_BASE_URL=http://localhost:5000/api
```
## 5️⃣ Start Frontend Development Server
```bash
npm run dev
```
## 6️⃣ Open a New Terminal
Keep the frontend running and open another terminal.
## 7️⃣ Navigate to Backend Folder
```bash
cd backend
```
## 8️⃣ Install Backend Dependencies
```bash
npm install
```
## 9️⃣ Create Backend Environment File
```bash
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```
## 🔟 Start Backend Server
```bash
npm start
```
